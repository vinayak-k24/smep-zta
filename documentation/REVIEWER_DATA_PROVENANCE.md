# Data Provenance and Reviewer Checklist

The records in this package are generated illustrative benchmark records for workflow testing. They are not observations collected during the experiments described in the manuscript.

For a genuine empirical submission package, include:
1. Original raw event logs or observations.
2. A run manifest with dates, environment, software versions, random seeds, and run identifiers.
3. Exact definitions of TP, FP, TN, FN, and each reported metric.
4. The scripts and configuration used to transform raw logs into manuscript tables.
5. A mapping from each reported number to reproducible code output.
6. Explanations for exclusions, missing records, retries, and failed runs.
7. Reconciliation of the manuscript's 15,450 total scenario figure with its 12,400 adversarial scenario figure.
8. A repository or DOI that reviewers can access without requesting permission.

Suggested disclosure for this package:
'This archive contains generated illustrative benchmark records provided to demonstrate the analysis workflow and data schema. These records are not observations from the reported experiment and should not be interpreted as empirical evidence. The manuscript's experimental claims should be supported by the original study logs, which should be deposited separately when available.'
